# TiRTC Flutter API Sample

This directory is generated from the `tirtc_flutter` Example maintained in the TiRTC repository.

The default dependency is the hosted package `tirtc_flutter: 2.2.2`. Run `flutter pub get`
before opening or building the application for a supported platform.

For OHOS, use the OpenHarmony Flutter toolchain. Its standard plugin preparation step generates
the ignored HAR files referenced by the checked-in OHOS host project.
